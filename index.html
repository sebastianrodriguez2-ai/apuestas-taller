# Tablero de apuestas del taller

Este es el proyecto de apoyo del taller de terminal y Git. Los datos son ficticios — ninguna cuota aquí mueve dinero real. Todo lo que ves se construyó en vivo con VS Code, PowerShell y Git.

0 selecciones marcadas

01 · Partidos en juego

El tablero de esta noche

Cada fila es un partido. Cada botón, una cuota. Haz clic para marcarla — se suma al contador de selecciones arriba.

02 · Cómo se lee el tablero

Tres columnas, una lógica

lectura-de-cuotas.md 
# 1 · Local
Gana el equipo de casa.

# X · Empate
El partido termina igualado.

# 2 · Visitante
Gana el equipo que juega fuera.

Entre más alta la cuota, menos probable
considera el mercado ese resultado.

La franja superior (el ticker) simula el movimiento de cuotas en vivo, como el marcador de un estadio.
